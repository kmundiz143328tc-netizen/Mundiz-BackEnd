# Mundiz-Final-Backend
Laravel REST API for School Management System

## Setup Instructions
```bash

1. clone my repository
2. cd Mundiz-Final-Backend
3. composer install
4. cp .env.example .env
5. php artisan key:generate
6. php artisan migrate --seed
7. php artisan serve


```
